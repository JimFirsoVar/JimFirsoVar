# Тест-кейс: Проверка кнопки "Сравнить продукты"

**Предусловие:**
- Пользователь не авторизован
- Есть доступный товар

**Шаги:**
1. Перейти на https://darkheresy.owlcat.games/preorder/ru/basket  
2. Добавить товар в корзину  
3. Пролистать до блока "Вам также может понравиться"  
4. Нажать на кнопку "Сравнить продукты"

**Ожидаемый результат:**
- Пользователь переходит на страницу сравнения товаров
