# Тест-кейс: Валидация поля "Имя пользователя" при регистрации

**Предусловие:**
- Открыта страница регистрации
- Пользователь не авторизован

**Шаги:**
1. Ввести в поле "Username": `' OR '1'='1`
2. Ввести валидный email
3. Ввести валидный пароль
4. Отправить форму регистрации

**Ожидаемый результат:**
- Появляется ошибка: "Имя пользователя содержит недопустимые символы"
- Регистрация не завершается
