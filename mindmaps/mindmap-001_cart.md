# Mind Map: Тестирование корзины и рекомендаций (по багу "Сравнить продукты")

- Корзина (основная ветка)
  - Добавление товара
  - Удаление товара
  - Изменение количества
  - Проверка итоговой суммы
  - Оформление заказа

- Блок "Вам также может понравиться"
  - Появление блока при товарах в корзине
  - Корректность рекомендаций (название, изображение, цена)
  - Добавление рекомендованного товара в корзину

- Кнопка "Сравнить продукты" (внутри блока рекомендаций)
  - Отображение кнопки
  - Активность кнопки
  - Доступность для неавторизованных пользователей
  - Корректность перехода (страница сравнения)
    - Корректный URL
    - Нет ошибки 404 *(баг)*
  - Проверка поведения с пустой корзиной/разными товарами

- Ошибки/Исключения
  - 404 при переходе
  - Пустая страница
  - Неправильный список для сравнения
  - Сообщения об ошибках для пользователя

- Адаптивность (минимально, по UI)
  - Видимость кнопки и блока на разных устройствах
